StayAwake

Stop your Windows PC from sleeping — from a web UI or a one-word command. Safely switch back anytime.

Install (Windows, PowerShell)

irm https://stayawa.ke | iex

Downloads a single stayawake.exe to %LOCALAPPDATA%\stayawake, adds the stayawake command to your PATH, and launches the app. No runtime, no admin required.

Why

Single tiny exeOne self-contained binary — no runtime to install. Just calls the built-in powercfg. Nothing leaves your machine; the server only listens on 127.0.0.1.
Safe restoreSaves your defaults and previous values, in powercfg's native units, so switching back is exact.
Web UI or CLIToggle from a browser, or run stayawake on/off/default headless. Same logic, same result.
Core + advancedSleep/hibernate/display/disk by default; opt in to processor-state and hidden CPU knobs.

Commands

CommandAction
stayawakeOpen the web UI
stayawake onPrevent sleep now
stayawake offRestore previous values
stayawake defaultRestore Windows defaults
stayawake uninstallRestore defaults and remove everything
